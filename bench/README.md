## Формат `задачи/<id>.yml`

```yaml
id: t1-…                 # = имя файла
размер: малая|средняя|большая
репо: TalismanOnline
репо_путь: ~/Projects/TalismanOnline
снимок: <коммит>         # с него стартует агент (до решения)
эталон: <коммит>         # эталонное решение (для большой — конец последнего этапа)
задание: |               # текст для агента
скрытые_тесты: [пути]    # берутся из эталона и кладутся в каталог на время проверки
проверка: |              # bash, cwd — корень репо; код 0 — успех
# большая — вместо задание/скрытые_тесты/проверка:
граница: |               # что делает прогонщик между этапами
этапы:
  - {имя, эталон, задание, проверка, скрытые_тесты?}
```

В `проверка` доступны `$BENCH` (эта папка), `$CAND` (проверяемый каталог), `$REPO` (исходный репо), `$REF` (эталон этапа).
Скрытые тесты plexus — `проверки/*.py` и `lib/самопроверка_эталона.py` (самопроверка эталонного скрипта гоняет скрипт кандидата).
Сеть не нужна: Go идёт с `GOPROXY=off GOFLAGS=-mod=readonly` на локальном кэше модулей.

## Проверка

```bash
bench/check.sh t1-план-счетов-409                 # эталон — зелёный (0)
bench/check.sh t1-план-счетов-409 --ref снимок    # снимок — красный (1)
bench/check.sh t5-дорожки-opencode --этап 1       # только этап 1 (эталон этапа 1)
bench/check.sh t2-имя-эпика --dir <каталог>       # решение агента
```

Коммит поднимается временным `git worktree` во временном каталоге и снимается после прогона.
Коды: 0 — пройдено, 1 — не пройдено, 2 — сбой подготовки. Нужны git, python3 с PyYAML, go (для Talisman).
