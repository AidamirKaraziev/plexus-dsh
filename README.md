# plexus-dsh

Бандл из четырёх плагинов для DSH (DeepSeek Harness): поставил одной строкой — в профиле появились все четыре. Они экономят деньги и контекст в длинных сессиях и показывают, сколько осталось в лимите.

## Что внутри

| Пакет | Что делает |
| --- | --- |
| `meter` | После каждого хода пишет $ и % окна лимита (5 ч, по всем сессиям) в журнал учёта. |
| `warm` | В паузе человека повторяет последний запрос модели, пока кэш провайдера жив, — новый ход не платит за перезапись префикса. |
| `read-cap` | Режет результаты `read`, `grep` и `bash` длиннее порога: голова и хвост плюс подсказка, как дочитать. |
| `scout` | Поиск и чтение в дочернем процессе на дешёвой модели; родителю возвращается только итог. |

Один пакет в списке Plugins, одна версия на все четыре плагина, настройки каждого — в Settings.

В бандл не входят `hello` (проверка каркаса) и `budget` (стоп-кран по бюджету): они ставятся поштучно, когда нужны.

## Установка

Пошаговая инструкция со скриншотами лежит в [УСТАНОВКА.md](УСТАНОВКА.md). Там же описаны проверка, обновление и что делать после обновления DSH.

Коротко: маркет плагинов в DSH экспериментальный, поэтому сначала его включают, потом добавляют индекс этого репозитория.

1. Откройте DSH (Web или Desktop) и перейдите в **Plugins** (Плагины) в боковой панели.
2. В разделе **Experimental plugins** (Экспериментальные плагины) включите **Custom plugin indexes** (Пользовательские индексы плагинов). Появятся вкладки **Installed** (Установлено) и **Discover** (Откройте для себя).
3. Во вкладке **Discover** нажмите «Добавить источник индекса» и добавьте URL:

   ```
   https://raw.githubusercontent.com/AidamirKaraziev/plexus-dsh/main/market.json
   ```

4. В списке появятся два плагина. У каждого нажмите **Install** (Установить), подтвердите в окне, затем нажмите **Включить сейчас**:
   - **Plexus DSH** (`@plexus-dsh/bundle`) — бандл из четырёх плагинов: `meter`, `warm`, `read-cap`, `scout`;
   - **@plexus-dsh/plexus** — Плексус: 14 команд `/plexus-*` и работники `plexus-programmer`, `plexus-analyst`; пакет выпускает Плексус.

### Как проверить, что встало

- **Installed → Plexus DSH**: в «Компонентах» написано «4 всего · 4 работает».
- В новой сессии `/plexus-help` отвечает списком команд.

### Запасной путь: из npm

Если маркет не включается, бандл ставится из командной строки (нужен npm-доступ к `@plexus-dsh`):

```bash
dsh plugin --profile <профиль> add @plexus-dsh/bundle@0.1.1
```

Плагины добавляются в профиль в порядке `meter`, `warm`, `read-cap`, `scout`. Плексус ставится так же:

```bash
dsh plugin --profile <профиль> add @plexus-dsh/plexus
```

## Совместимость

Бандл собран под DSH `0.2.2-rc.5` (`engines.dsh`) и Cordis 4.1: форма хуков цикла агента между релизами меняется. Если DSH новее, ставьте бандл, помеченный его версией, или разрешите пару командой `dsh plugin allow-version`.
