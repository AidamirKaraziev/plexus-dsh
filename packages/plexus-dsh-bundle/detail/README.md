# Plexus DSH

Четыре плагина продукта в одном бандле: поставил строкой — в профиле DSH появились все.

| Пакет | Что делает |
| --- | --- |
| `meter` | После каждого хода пишет $ и % окна лимита в журнал учёта. |
| `warm` | В паузе человека повторяет последний запрос модели, пока кэш провайдера жив. |
| `read-cap` | Режет результаты `read`, `grep` и `bash` длиннее порога. |
| `scout` | Поиск и чтение в дочернем процессе на дешёвой модели; родителю — только итог. |

## Установка

```bash
dsh plugin --profile <профиль> add <путь-к-tarball-или-каталогу>
```

Один пакет — одна строка в Plugins, одна версия на все четыре плагина, настройки
каждого — в Settings. Всасывать по пакету не нужно: строки вставляются патчем
бандла в порядке `meter`, `warm`, `read-cap`, `scout`.

## Чего в бандле нет

`hello` — дым для проверки каркаса, `budget` — стоп-кран по бюджету. Они ставятся
поштучно, когда нужны: бандл не должен тащить в профиль сторожей, о которых
не просили.

## Совместимость

Пакеты собраны под точную версию DSH (`engines.dsh`) и Cordis 4.1: форма хуков
цикла агента между релизами меняется. Если DSH новее — ставьте бандл той версии,
что помечена его версией, или разрешите пару точной командой `dsh plugin allow-version`.
